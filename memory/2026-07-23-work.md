### 5. 回答记录创建时机修复

**问题**：`handleGenerate()` 和 `confirmRetryQuestion()` 在用户进入答题界面时立即创建空回答记录，即使不答题直接返回也留下空记录。

**修复**：将创建回答记录的调用从 `handleGenerate()` 和 `confirmRetryQuestion()` 中移除，移到 `handleStartAnswer()` 中（用户真正点击「开始回答」时创建）。

**草稿续答完善：**

| 场景 | 行为 |
|------|------|
| 草稿恢复 → 继续录音 → 完成 | 草稿文本 + 新 ASR 文本拼接为完整回答 |
| 草稿恢复 → 不录音 → 直接完成 | 草稿文本原样提交 |
| 草稿恢复 → 再次中途退出 | 草稿文本 + 新文本合并保存 |
| 草稿恢复 → 暂停 → 退出 | 同↑ |

**核心机制：** `STATE._draftRestoredText` 标记草稿恢复模式，所有文本拼接处（`handleDoneAnswer`、`saveDraft`、`handleBackToTrain`、ASR 显示）都检查该标记，确保草稿文本不会被新 ASR 文本覆盖。

**涉及文件：** `frontend/js/pages/agent.js`
