# 2026-09-03 工作记录

> 本轮工作跨 09-02 晚 ~ 09-03，围绕技能树模块展开：编辑器 bug 修复 → AI 功能全链路审查 → 技能树 AI 重写为 LangGraph 架构。

## 一、技能树编辑器 bug 修复（8 项）

### 高危 4 项

1. **预览模式崩溃**：`app.js` `initPreviewMode()` 调用不存在的 `renderer.renderAll()`（TreeRenderer 只有 `renderAllNodes`）→ TypeError 且 clearInterval 执行不到，定时器每 100ms 报错持续 5 秒。改为 `updateLearningStates() + this.renderAll()`。
2. **对齐参考线从未生效**：参考线在构造时 append 到 connectionLayer，但 `renderConnections()` 用 innerHTML 整体重建图层，首次渲染后参考线被冲成游离 DOM。修复：重建后重新 append；连线模式临时虚线用 `isConnected` 检测自动重新挂载。
3. **右键删除连线残留**：`deleteNode()` 不重渲染连线，节点删了线还挂着；且不入撤销栈。修复：删除后 `renderConnections()`（加 `deferRender` 选项供批量删除），右键删除补齐 saveHistory/重名检测/发布按钮/统计刷新完整流程。
4. **跨树撤销数据污染**：`loadData()` 每次压快照 → 切到树 B 后撤销恢复树 A 内容，保存时 A 写进 B。修复：`history.clear()` + 加载后压基线快照（保首次编辑可撤销）。

### 中等 4 项

5. **redo 失效**：历史栈语义为「改后快照」，但 saveNodeEdit/markNodeAsLearning/markNodeCompleted/deleteSelectedNodes 等是改前 push。全部统一为改后 push；`newTree()` 补空树基线；ai-bridge 6 处工具调用同步统一（create_node 原双 push 膨胀栈，删外层）。
6. **上线 toast**：`publishTree()` 先赋值 `publishedAt` 再做三元判断，首次上线也显示"已更新"。改用 `isUpdate` 局部变量先捕获；`updatePublishedTree()` 删叠加的重复 toast。
7. **tooltip 监听器累积**：`renderNode()` 复用 el 但每次 `_attachTooltip` 都 addEventListener → 内存泄漏。用 `el.__tooltipBound` 标记只绑一次，回调内动态取最新 tooltip。
8. **初始化竞态**：sidebar `_initIndex()` 的自动 switchToTree 分支与 App.initDefaultTree 并发加载（且 user 模式下会用草稿覆盖发布版）。删除该分支，树数据加载统一收敛到 App。

## 二、技能树 AI 功能审查

发现**双轨并行架构**：旧链路（`ai-bridge.js` → `/api/chat` → `ai_service.py` 裸 httpx，按节点名称匹配工具）实际在用；新链路（`/api/skill-trees/{id}/chat` → LangGraph `skill_tree_ai/` 模块，ID 匹配 + 确认机制）从未被前端调用，属死代码。

核心问题：graph.py 缺 `HumanMessage` import（一调用就 NameError）、旧 `/api/chat` 全后端唯一无鉴权 AI 端点（烧配额风险）、旧链路固定读 .env（模型动态切换不生效）、前端 `slice(-20)` 截断可产生孤儿 tool 消息（API 400）。

## 三、技能树 AI 重写为 LangGraph（全栈）

### 后端（services/skill_tree_ai/）

- **graph.py**：补 HumanMessage import；thread_id 改为每会话生成 `stc_{uuid16}`（原固定 `skill_tree_{tree_id}_{user_id}` 导致同树所有对话共享 thread 永不隔离）；`_format_result` 增加 reply 兜底（用 executed_tools 拼摘要）。
- **state.py**：`diffs`/`executed_tools` 从 `operator.add` 改为普通字段——原来在 checkpointer 中跨调用累积，旧 diff 重复返回给前端重复应用。
- **node.py**：新增 `_truncate_messages()`，截断边界自动跳过 ToolMessage（防孤儿 ToolMessage 导致 API 400）。
- **tools.py**：`create_nodes_batch` 新增 `parent_id` 参数（批量节点中的"根"自动挂到父节点，支撑"为节点扩展子树"场景）；连线解析支持名称/ID 混合；`parent_id` 签名改 `str | None` 容忍 LLM 传 null。
- **prompts.py**：删除未使用的 legacy import（循环依赖风险）。

### 旧链路下线

- `main.py` 移除 `ai_router` 注册，`routers/__init__.py` 移除导出（留注释说明），`routers/ai.py` 标记 deprecated（文件保留作参考）。OpenAPI spec 验证 `/api/chat` 已不可访问，新端点已注册。

### 前端（ai-bridge.js 全部重写）

- 调 `/api/skill-trees/{id}/chat`（带 user_id 鉴权），前端只持 thread_id，会话由服务端 checkpointer 维护 → **模型动态切换随之生效**。
- `_applyTree`：不走 loadData（会清撤销栈），手动压改前/改后快照 → **AI 修改可用 Ctrl+Z 撤销**。
- `_renderConfirmCard`：危险操作渲染确认/取消按钮 → `/chat/resume`。
- `resetSession`：切树/新建/删除树时重置（sidebar.js 三处挂载）；AI 面板新增 🗑 清空对话按钮。
- `expandNode` 自动打开 AI 面板；快捷按钮改 data-fill 填充模式（修复"请为生成…"语病）；CSS 新增 `.ai-confirm-card` 样式。

### 验证

- pixi 环境运行时测试：graph 编译成功、9 工具注册、截断无孤儿 ToolMessage
- 工具功能测试：批量创建+挂接、删除确认守卫+级联删除、replace 确认守卫、重名自动改名——全部通过
- OpenAPI spec 验证端点注册；前端 node --check 通过
