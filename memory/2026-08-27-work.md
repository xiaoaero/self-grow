# 2026-08-27 工作记录

## 协调 Agent 反问机制重构（三段式）

将子 agent 的反问从 LangGraph `interrupt()` + `Command(resume)` 挂起恢复，改为 `ask_user` 工具 + 消息续答，彻底解决 resume 时子图上下文丢失、重复调 LLM 的问题。

### 三段式架构（用户拍板）

1. **主 agent 路由**（router_node）：自然语言 → 决定启动哪些次 agent + 定制指令
2. **子 agent 反问与执行**：并行派发，缺信息时 `ask_user` 反问，用户回答**直接接回该子图上下文**（不重新路由），循环
3. **主 agent 总结**（synthesize_node）：所有子 agent 完成后整合回复

### 核心改动

- `agents/base.py`：`make_agent_node` 改用 ask_user 工具（返回 `result.needs_user`），移除 `interrupt()`/`clarify_on_text`
- `graph.py`：主编排从 StateGraph 改为纯函数 `run_coordinator` + `resume_subgraph`
- `routers/coordinator.py`：resume 改消息续答，**修复多域 interrupt 被覆盖的 bug**（原回答 A 域会丢掉 B 域的反问）
- `state.py`：`CoordinatorState` 简化为普通 dict 结构

### 实测结论

- resume 每次只多 **1 次 LLM 调用**（旧 interrupt 方案是 +2 次，问题上下文丢失导致重问）
- 真实 AI 端点（`qwen3.7-plus`，阿里云 maas）已恢复，HTTP 200（08-23 记录的配额耗尽已解决）
- LangGraph 实装版本 **1.2.11**（`pixi.toml` 声明 `>=0.2.0`，存在版本漂移）

## 协调 Agent 上下文管理

### 记录（Record）定义

一次「主分发 → 子循环 → 主总结」= 一条记录，**三阶段全走完才计入历史**（失败总结也计入）。

### 主 agent 上下文（跨记录，近 5 条）

- 每条记录只存 `{用户说的话, 主agent总结}`，**不含 dispatch 指令和子 agent 执行过程**
- `finalize_record()` 在总结完成后压入，FIFO 截断到 5 条
- `router_node` 路由时注入近 5 条摘要，判断「延续 vs 新任务」
- 存储：后端内存 `_thread_store[thread_id].records`；前端 `sessionStorage` 存 thread_id（**刷新不丢、关闭才丢**）

### 子 agent 上下文（单记录，3 轮）

- 窗口保留最近 3 轮 + 反问最多 3 次，超限降级（移除 ask_user 工具，逼 LLM 用默认值执行或输出「信息不足放弃」）
- 6 个 `*SubgraphState` 加 `ask_rounds` 字段（checkpointer 持久化）

## 经验计算修复

- `exp_service.py`：修复 `exp_result.get("exp", 0)` → `exp_result.get("dimension_exp", 0)`。`calculate_exp` 返回键是 `dimension_exp`/`global_exp`，原代码取不存在的 `exp` 键导致**经验恒为 0**
- `action_agent.py`：`record_action` 加 `sub_type` 参数，链路透传到 `calculate_exp`
- `prompts/coordinator.py`：action agent 提示词加 8 维度计分规则 + sub_type 枚举（LLM 只判断 sub_type，后端计算数值）

## 工具参数完善

- 4 个 agent 提示词强化「ID 只能通过 list 查询获取」（goal_id/task_id/habit_id/reward_id 都是数据库主键，用户无法直接提供）
- `task_agent.py`：`create_task` 明确 `category` 枚举（8 维度）+ `exp` 改为**必填**（由用户指定，没说就反问）
- 输出全部 25 个工具的所需参数清单

## 前端修复

- `chat.js`：反问卡片**回复后立即关闭**（`resumeInterrupt` 移除队列后立即 `_refreshInterruptArea`，原来要等 fetch 返回）
- `chat.js`：悬浮球**拖拽方向反转**修复（`style.bottom` 多写了 `window.innerHeight -`）
- `action_agent.py`：去掉 `request_id`（原来每次都生成新 uuid，幂等永不生效，反而 `[req:uuid]` 前缀污染历史备注）
