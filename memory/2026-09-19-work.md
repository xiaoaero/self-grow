### 🔍 用户容器的实测问题：**时区没设**

```
字符集  utf8mb4 / utf8mb4_unicode_ci          ✅ 对
时区    ❌ 没有 TZ，也没有 --default-time-zone  → 容器跑在 UTC
库名    ai_project（别的项目的库）
```

`NOW()` 会比本地时间早 8 小时 —— **正是本项目前一天刚踩过的坑**。
**解法不用重建容器**：PyMySQL 建连时 `init_command="SET time_zone = '+08:00'"`，与容器时区解耦。
另建议新建 `self_grow` 库，别复用 `ai_project`。

### 方案要点

1. **双后端 + 分阶段**：`SELF_GROW_DB_BACKEND=sqlite|mysql`，随时回退（这是能做的前提）
2. **连接池 + 代理对象**（`DBUtils.PooledDB`）：让既有模式一行不改
3. **占位符两条路**：A 连接层 `?`→`%s` 翻译（1 小时跑通）、B 老实改 150 处 → **先 A 后 B**
4. **时间统一应用侧 `now_str()`**，不用 MySQL 的 `NOW()` —— 与项目既有时间口径约定一致
5. **时间列保持 TEXT 字符串，不改 DATETIME**（有意保留的取舍：改类型会牵动所有比较/分组/前端格式）
6. 数据迁移：显式列字段名、保留 id、**迁完重置 `AUTO_INCREMENT`**、逐表比行数与聚合值
7. 8 项验证清单（含专门跑 `test_time_consistency` 与 `test_dimension_invariant`）

## 三、踩的坑（10 条，都是"跑起来才炸"的那种）

1. **反引号与 DDL 转换的顺序**：先 `quote_reserved` 再加反引号 → `` `desc` TEXT DEFAULT '' ``
   匹配不到"列名 TEXT"的正则 → 没转成 VARCHAR → **1101**。
   **必须先做方言转换、再加反引号。**
2. **幂等标记不能放 `VARCHAR(`**：源码里为兼容 MySQL 已把几列声明成 VARCHAR，
   结果含 VARCHAR 的建表语句被判定"已转换"而跳过 → 自增主键没换 → **1064**。
   幂等标记只能放 **SQLite 语法里绝不会出现**的特征（`AUTO_INCREMENT` / `ENGINE=`）。
3. **TEXT 出现在"键位置"就会炸（1170）**，三种位置都要覆盖：
   列级 `DEFAULT`/`UNIQUE`、表级 `PRIMARY KEY(...)`/`UNIQUE(...)`、
   独立的 `CREATE INDEX ... ON t(col)`。**漏一个就在建表时炸一次**（踩了 `desc`、`tree_id`、`date` 三次）。
4. **保留字**：用 `information_schema.keywords`（262 个）跟项目 101 个列名比对，
   只有 `desc` 和 `year_month` 冲突。
   ⚠️ 转的时候**要保护 `ORDER BY ... DESC`**（16 处）。
5. **`ON CONFLICT ... DO UPDATE SET` + `excluded.col`**（7 处 upsert）→
   `ON DUPLICATE KEY UPDATE` + `VALUES(col)`。
6. **连接池太小会死锁且无超时**：池 12 时 `test_sleep_action`（每用例 DROP + CREATE 22 表）
   **卡死**；提到 40 立刻通过。默认已改 **20**。
   **DBUtils 的 `blocking=True` 是无限等待** —— 这是真实的生产风险。
7. **测试隔离在 MySQL 下失效**：既有 fixture 靠 `monkeypatch DB_PATH` 换库文件，
   MySQL 没有文件可换 → 测试直接写真实库。新增 `reset_test_database()` 做"删表重建"。
8. **`date()` 返回类型不同**：SQLite 返回字符串，MySQL 返回 DATE → PyMySQL 转 `datetime.date`。
   测试断言统一 `str()` 后比较（业务逻辑不受影响，MySQL 隐式转换正常）。
9. **PyMySQL + DBUtils 的安装**：`pixi add pymysql` 走 conda-forge 会因网络失败 →
   改用 `pixi add --pypi pymysql`。
10. **pixi 缓存目录**：沙箱不允许写 `%LOCALAPPDATA%\rattler` →
    用 `RATTLER_CACHE_DIR` / `PIXI_CACHE_DIR` 指到项目内。
