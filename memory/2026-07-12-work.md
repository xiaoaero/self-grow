### 技能树存储迁移：localStorage → 后端 API

#### 动机
技能树数据全部存储在浏览器 `localStorage` 中，清缓存、换域名或换设备时数据丢失。

#### 后端（3 新建 + 3 修改）
- `backend/db/skill_tree.py` — **新建**：10 个 CRUD 函数（get/list/create/save_draft/publish/get_published/save_learner/delete/user_skills）
- `backend/routers/skill_tree.py` — **新建**：10 个 API 端点
- `backend/db/init.py` — 新增 `skill_trees` 和 `user_skills` 两张表
- `backend/routers/__init__.py` — 注册 `skill_tree_router`
- `backend/main.py` — 注册路由

#### 前端（4 修改）
- `frontend/skill-tree/js/utils.js` — 新增 8 个后端 API 函数（`fetchSkillTreeIndex`、`createSkillTreeOnServer` 等）
- `frontend/skill-tree/js/sidebar.js` — 索引/创建/保存/发布/删除改为优先后端
- `frontend/skill-tree/js/app.js` — 加载/保存学习进度改为优先后端
- `frontend/js/pages/skills.js` — 全部数据加载改为异步优先后端

#### 设计要点
- **降级策略**：后端在线 → 读写数据库；后端离线 → 自动降级 localStorage
- **兼容性**：`tree_id` 格式不变，所有 URL 参数和 iframe 传参无需改动
- **自动同步**：localStorage 有数据时，下次操作自动同步到后端
- **业绩影响**：仅加载/保存时各一次 HTTP 请求，编辑器拖拽等交互完全不受影响

#### 验证结果
全部 11 个 API 端点通过 TestClient 端到端测试 ✅
