# 2026-07-27 工作记录

## 仪表板 / 成长记录 / 属性面板 代码审查与修复

### 审查背景
对 dashboard.js、history.js、attributes.js 三个核心页面进行代码审查，发现并修复了 7 个潜在问题。

### 修复清单

| # | 模块 | 问题 | 改动 |
|---|------|------|------|
| 1 | 仪表板 | `Promise.all` 单个失败丢弃全部结果 | 改为 `Promise.allSettled`，各自独立处理 profile/habits |
| 2 | 仪表板 | `recentActivities.map` 中 `act.category` 缺失时 `getCategory` 返回 undefined 导致 `cat.id` TypeError | 提取 `catHtml` 变量，无分类时跳过标签渲染 |
| 3 | 成长记录 | `drawProfileRadarChart` 只清理 `canvas._chart`，Chart.js 注册表残留 | 增加 `Chart.getChart(canvas)` 双重清理，与 `drawTrendChart` 一致 |
| 4 | 成长记录 | `renderYearlyHeatmap` 入口无空数组守卫，`Math.max(...[])` 返回 -Infinity | 函数入口加 `!activityData || activityData.length === 0` 提前返回空状态 |
| 5 | 成长记录 | 趋势图后端无数据时生成全零模拟曲线，体验差 | 改为显示 "暂无数据" 提示，不画零线 |
| 6 | 属性面板 | `d.xp`/`d.xpToNext` 可能为 undefined/0 导致除零或 NaN | `d.xp || 0` / `d.xpToNext || 1` 安全默认值 |
| 7 | 属性面板 | `renderAttributes` 每次调用重复请求 `fetchProfileStats`（app.js 已加载过） | 优先从 `AppData.profile` 读取，数据缺失才请求后端 |

### 涉及文件

| 文件 | 改动 |
|------|------|
| `frontend/js/pages/dashboard.js` | #1 `Promise.all` → `Promise.allSettled`；#2 `catHtml` 防御 |
| `frontend/js/pages/history.js` | #3 `Chart.getChart` 双重清理；#4 热力图空数组守卫；#5 趋势图空数据提示 |
| `frontend/js/pages/attributes.js` | #6 除零/NaN 安全默认值；#7 避免重复 API 调用 |

## 技能树代码审查与修复

### 审查背景
对 skill-tree 板块全部前端+后端代码进行审查，发现 7 个有效问题，按优先级修复。

### 修复清单

| # | 模块 | 问题 | 改动 |
|---|------|------|------|
| 1 | 前端 App | 节点名称重复检测缺失 | 新增 `checkDuplicateNames()` 和 `hasDuplicateNames()`，同名节点自动添加红色光圈（CSS `.node-name-duplicate` + 呼吸动画），阻止发布/更新但允许保存 |
| 2 | 前端 App | `saveNodeEdit` 中 `this.nodes[0].name === node.name` 语义错误 | 删除该无用逻辑，树名只通过侧边栏"更改介绍"修改 |
| 3 | 前端 App | `replaceTree` 中树名=`nodes[0].name` 语义错误 | 改为从用户消息提取主题名 |
| 4 | 前端 History | 历史栈 shift 后 index 不更新 | `this.index = Math.min(this.stack.length - 1, this.index + 1)` |
| 5 | 前端 AI | AI 工具 create_node/update_node/delete_node 后未触发重复名称检测 | 各工具执行后追加 `app.checkDuplicateNames()` 和 `app._updatePublishButtons()` |
| 6 | 后端 DB | `delete_skill_tree` 无存在性检查 | 返回 `cursor.rowcount > 0` 替代固定 True |
| 7 | 前端 TreeRenderer | 节点渲染缺少 `_nameDuplicate` 样式绑定 | 新增 `.node-name-duplicate` class toggle |

### 涉及文件

| `frontend/skill-tree/js/app.js` | #1 新增 `checkDuplicateNames`/`hasDuplicateNames`；#2 删除树名错误逻辑；#3 修复 `replaceTree` 树名；所有增删改节点处调用检测 |
| `frontend/skill-tree/js/tree-renderer.js` | #7 `_nameDuplicate` class 绑定 |
