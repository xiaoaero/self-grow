# 2026-07-21 工作记录

## 今日完成

### 表达训练系统（AI Agent 扩展）完整实现

**背景：** 侧边栏「扩展 → AI Agent」从占位页面升级为完整的表达训练系统。用户通过 AI 出题、回答问题、AI 评分来锻炼表达能力。

#### 数据库

- **`backend/db/init.py`** — 新增 `expression_questions`（题目表）和 `expression_answers`（回答表）建表逻辑
- **`backend/db/expressions.py`** — **新建**，完整 CRUD：
  - 题目：创建、查询、查重（用于 LLM 防重复出题）、更新提示
  - 回答：创建、更新文本、更新评分、按题目查询、按用户查询历史
  - 统计：累计回答数、训练天数、题型分布、平均分

#### 后端 API

| 端点 | 方法 | 说明 |
|------|------|------|
| `/api/expression/generate` | POST | LLM 出题（Tool Use 模式：查历史 → 生成题目 + 3 条提示） |
| `/api/expression/answer` | POST | 创建回答记录 |
| `/api/expression/answer/{id}/text` | POST | 提交回答文本 + 填充词统计 |
| `/api/expression/generate-hints` | POST | 异步生成提示（表达方向 + 例子），不阻塞答题 |
| `/api/expression/evaluate/{id}` | POST | AI 多维度评分 + 优点 + 待改进 + 综合建议 |
| `/api/expression/stats` | GET | 总训练统计数据 |
| `/api/expression/history` | GET | 最近回答记录列表 |
| `/api/expression/question/{id}` | GET | 题目详情 + 该题下所有回答 |
| `/api/expression/answer/{id}` | GET | 单条回答详情 |

#### 提示词模板

- **`backend/prompts/expression.py`** — 3 套提示词：
  - 出题提示词（要求不重复、有讨论空间、输出格式严格）
  - 评分提示词（4 维度评分：流畅度/逻辑性/内容质量/语言表达）
  - 提示生成提示词（生成表达方向 + 2-3 个具体例子）

#### 业务逻辑层

- **`backend/services/expression_service.py`** — 核心逻辑：
  - `generate_question()` — LLM Tool Use 出题（查询历史防重复 + 联网搜索预留）
  - `evaluate_answer()` — LLM 评分 + 存储
  - `generate_hints()` — 异步生成提示（不阻塞答题）
  - 降级容错：AI 不可用时自动使用预设题目/评分
