# 2026-09-01 工作记录

## MCP 插件（工具级暴露）

把 Self Grow 的 24 个业务工具通过 MCP 协议暴露，任何支持 MCP 的客户端（Claude Desktop / Cursor / WorkBuddy）都能用自然语言管理个人成长数据。

### 核心内容

- `backend/mcp_server.py`：用 FastMCP v2（`from fastmcp import FastMCP`）注册 6 域 24 个工具（action/query/goal/task/habit/reward），工具内部直接复用 `db/`、`services/` 层零重写
- 传输：默认 stdio（本地客户端 spawn），支持 `MCP_TRANSPORT=streamable-http` 切 HTTP 远程
- 单用户模式：`SELF_GROW_USER_ID` 环境变量（默认 1 = test 用户）
- `backend/test_mcp_client.py`：FastMCP Client 一键验证脚本（不依赖第三方客户端/Node.js）
- `pixi.toml`：加 `[pypi-dependencies] fastmcp` + `mcp` task
- `docs/MCP插件说明.md`：安装/运行/挂载/验证文档

### 参数约束（LLM 缺参/传错值的防护）

- **枚举**用 `typing.Literal` 约束（category 8 维 / sub_type 12 子类型 / priority / task status / source_type / checkin status / active），生成 JSON Schema enum，非法值调用前拦截
- **数值范围**函数内校验：任务 exp 10~500、习惯 weekly_target 1~14、xp_reward 5~100、目标 reward_exp 0~9999、里程碑 5~20
- **打卡只能今天**：`checkin_habit` 去掉 date 参数，内部固定今天
- **start_time**：`record_action` 必填（LLM 需明确开始时间）

## 经验幂等 bug 修复

- `exp_service.py`：`create_action_log` 写入时 `exp_earned` 先占位 **0**，`award_exp_and_recalc` 后回写真实值。原代码写入时就写 `dimension_exp`（>0），导致幂等检查 `exp_earned > 0` 误判为「已奖励」，跳过经验结算（历史有记录但维度/全局/今日统计都不变）

## 用户中心

### 入口

- 侧边栏左下角用户框（`renderSidebarFooter`）段位名右侧加 **SVG 箭头**，整块可点 → `navigateTo('usercenter')`，悬停高亮 + 箭头右移动效

### 页面（`js/pages/usercenter.js` + `pages.css`）

- **基础信息卡**：大号等级徽章（段位渐变）+ 用户名/角色标签 + 等级·段位 / 总经验 / 注册时间 / 用户ID
- **模型信息卡**：文本模型(LLM) / 语音模型(ASR) 两组，每组可 添加/编辑/删除/点击切换启用，启用卡片金色左边框 + 「● 启用中」徽章，api_key 脱敏显示
- 添加模型弹窗：类型由「添加」按钮决定（不在弹窗内选）；含「测试连通性」按钮

## 模型配置持久化 + 动态生效

### 数据层

- 新建 `model_configs` 表（user_id/type/name/model/base_url/api_key/is_active），`db/model_configs.py` CRUD + `set_active`（同类型互斥）+ `get_active_config`
- `db/init.py` 建表 + 为无配置用户插入默认 LLM（.env）/ASR（paraformer）
- `routers/model_configs.py`：5 端点（列表/新增/编辑/删除/切换）+ `POST /test`（LLM 发 ping 测连通性）

### 动态生效（切换模型即时生效）

AI 服务从「读 .env 常量」改为「读当前启用配置」，缓存 key 含 model/base_url/api_key，切换后自动重建实例：

| 服务 | 改动 |
|------|------|
| coordinator/llm.py | get_llm 加 user_id，动态读 get_active_config |
| coordinator/router_node / synthesize_node / agents/base | 传 state 的 user_id |
| ai_client.py | _get_llm + call_ai_text/stream 动态读取 |
| ai_habit_service.py + routers/habits.py | call_ai_for_icon 传 user_id |
| asr_service.py | ASRConnection 读启用 ASR 配置 |
| routers/expression.py + agent.js | WebSocket 带 user_id |

## 系统版本号

- `config.get_version()` 用 `git describe --tags --always`（返回 `v1.0.0-3-g0df2e08`），非 git 环境回退 `1.1.0`
- `/api/health` 返回 version，前端 `app.js` 拉取显示在**大页面右下角**（`.global-version` 固定定位）
