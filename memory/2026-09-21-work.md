## 三、修复仓库远端凭据配置

HTTPS 推送失败：

```
fatal: could not read Username for 'https://gitee.com': terminal prompts disabled
```

非交互环境下凭据助手弹不出窗口。本机有 `~/.ssh/id_ed25519`，
`ssh -T git@gitee.com` 认证通过（账号 `www-zhang-hang`）→ 把 remote 改为 SSH：

```
git remote set-url origin git@gitee.com:www-zhang-hang/self-grow.git
```

**这是持久修复**：以后推送不会再卡在凭据上。

> 附带说明：这也让 09-17 记录里那条「`origin` 是 HTTPS 而推送走 SSH，
> 导致 `git status` 缓存不更新」的坑**不再成立** —— 现在只有一个远端，不会有这种错位。

**推送后双向验证**：

| 检查 | 结果 |
|---|---|
| `git rev-list --left-right --count origin/master...master` | `0	0`（完全同步） |
| `git ls-tree -r origin/master` 查敏感文件关键词 | **无命中** —— 确认密钥没上去 |
| `git log --oneline origin/master -8` | 远端确实有新提交 |
