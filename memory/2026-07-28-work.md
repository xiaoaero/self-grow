### 自 v1.0 以来的全量更新内容

#### 新增功能
- **表达训练系统**（AI Agent）：AI 出题+查重（Tool Use）、答题计时、填充词检测 V2（四重规则）、AI 四维评分（流畅度/逻辑性/内容/语言）+ 改进建议
- **语音识别集成**：DashScope paraformer-realtime-v2 实时语音转文字 WebSocket 接入，支持麦克风诊断弹窗（双标签）
- **表达训练历史**：分页浏览/按题目分组展开/多 attempt 切换/AI 评分详情回顾 + 题型筛选/时间/回答次数筛选
- **习惯 AI 图标设计**：根据习惯名称/简介/维度调用 AI 生成自适应 SVG 图标
- **行动记录 CSV 导出**：前后端完整实现，支持分类/日期筛选，可选含 EXP 列
- **行动 AI 解析**：对话式交互 + Tool Use 多轮对话，AI 自动按精确计分规则计算 EXP 并 batch 提交

#### 后端重构
- 任务板块重构：source_type 三分离（today / daily / weekly）+ task_history 定时归档（每日 03:00 / 周一 03:05）
- 奖励商城条件引擎重构：增量快照机制（`unlocked_at_snapshot`），领取条件从解锁时刻做差值判断
- 奖励商城全面审查修复：10 项问题（鉴权/快照/图片上传/排序/条件必填校验/label 匹配等）
- 规律作息 EXP 系统完整实现：连续天数、保护机制（≥10天获保护）、作息规律检测（23:00~00:00 + 06:30~08:30）
- 后端模块化：AI 提示词整合到 `prompts/` 统一管理，新增 `ai_client` 统一调用层
- 经验规则重构：8 维独立计分（学习/运动/睡眠/关系/工作/创作/财务/爱好/魅力），各子类型公式不同，global_rate 折算机制

#### 前端完善
- 技能树编辑器重构：viewer/editor/admin 三模式，AI 助手 + 9 个 Tool Use 工具，后端持久化替代 localStorage
- 仪表盘/成长记录/属性面板代码审查修复：7+7 项修复
- 多项 bug 修复：任务数据污染/今日统计看板同步/completed_at/动态播报/侧边栏经验同步等
