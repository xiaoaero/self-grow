# 2026-07-14 工作记录

## 工作内容 1：弹窗点击外部关闭 bug 修复

### 问题
用户反馈：后几个板块（习惯、奖励、目标、任务）右上角的弹窗，设计上不应该通过点击弹窗外部来关闭，但实际点击外部会直接关闭。

### 根因
`frontend/js/app.js:91` 在应用启动时永久绑定了一个监听器：
```javascript
document.getElementById('modal-overlay').addEventListener('click', closeModal);
```
这个监听器直接调用 `closeModal()`，绕过了所有保护机制：
- 绕过了 `closeModalIfNotActive()` 的 `clickOutsideToClose === 'false'` 检查
- 绕过了 `e.target === overlay` 检查（点击弹窗内部也会触发关闭）
- 与 `openModal()` 中按需绑定的带保护监听器冲突

### 修复
`app.js:91` 改为：
```javascript
document.getElementById('modal-overlay').addEventListener('click', function(e) {
    if (e.target === document.getElementById('modal-overlay')) {
        closeModalIfNotActive();
    }
});
```

### 涉及文件
- `frontend/js/app.js` — 修复点击外部关闭逻辑

## 工作内容 6：桌面应用打包基础设施（Electron + PyInstaller）

### 目标
将项目从"命令行启动的 Web 应用"变为"双击图标即可使用的桌面应用"。

### 架构设计
```
SelfGrow.exe (Electron 主进程)
  ├── 启动 self-grow-backend.exe (PyInstaller 打包)
  ├── 等待后端就绪 (轮询 /api/health)
  ├── 创建 BrowserWindow 加载前端
  └── 关闭窗口 → 终止后端
数据目录: %APPDATA%/SelfGrow/
  ├── data.db / uploads/ / .env
```

### 后端改动
- **config.py**: 新增 `get_data_dir()` 支持打包模式
  - 开发模式 → `backend/` 目录
  - 打包模式 → `%APPDATA%/SelfGrow/`（通过 `SELF_GROW_PACKAGED` 环境变量切换）
  - `.env` 从数据目录加载，首次运行自动创建模板
- **main.py**: 新增 `/api/config.js` 端点（动态注入 `window.__SELF_GROW_API_BASE__`）
- **main.py**: 打包模式下后端直接 serve 前端静态文件（消除单独 HTTP server 需求）
- **self_grow_server.py**: PyInstaller 入口脚本（设置环境变量→启动 uvicorn）
- **self_grow_server.spec**: PyInstaller 打包配置（onedir 模式、hidden imports）

### 前端改动
- **Chart.js**: CDN → 本地 `vendor/chart.umd.min.js`（离线支持）
- **API_BASE**: 3 处硬编码 → `window.__SELF_GROW_API_BASE__ || 'http://localhost:3001'`
  - `utils.js`, `login.html`, `ai-bridge.js`
- **index.html / login.html**: 加载 `/api/config.js` 脚本

### Electron 项目（desktop/）
- **main.js**: 主进程（启动后端→等待就绪→创建窗口→单实例锁→关闭时停止后端）
- **preload.js**: 安全桥接（暴露 `electronAPI.isElectron`）
- **package.json**: electron-builder 配置（NSIS 安装包、桌面快捷方式、extraResources）
- **build/icon.ico**: 应用图标

### 构建脚本
- **build.bat**: 一键构建（PyInstaller → npm install → electron-builder）
- **dev.bat**: 开发模式一键启动（后端+前端+浏览器）

### 关键设计决策
- **后端 serve 前端**：打包模式下 FastAPI 直接挂载前端静态文件，技能树 iframe 相对路径自然工作
- **/api/config.js**：后端提供 JS 配置端点，前端动态获取 API 地址，开发/Electron 模式统一
- **数据目录分离**：用户数据（db/uploads/.env）在 `%APPDATA%/SelfGrow/`，不随安装目录走
- **.env 模板**：首次启动自动创建空模板，用户编辑添加 API Key

### 遇到的问题

**electron-builder + winCodeSign 符号链接权限问题**

`app-builder` 的 `rcedit` 步骤需要下载 `winCodeSign-2.6.0.7z` 并用 `7za.exe` 解压。解压时遇到 darwin 平台的符号链接文件，Windows 普通用户没有 `SeCreateSymbolicLinkPrivilege` 权限，7za 报 exit code 2，app-builder 视为致命错误。

- `sign: false` 配置无法绕过（rcedit 也需要 winCodeSign）
- portable 目标同样受影响
- 手动解压 + 占位文件无效（app-builder 每次重新下载解压）

**解决方案**：改用绿色版打包模式
1. `electron-builder --win --dir` 生成 `dist/win-unpacked/`（此步骤成功）
2. `make-portable.js` 自动添加启动脚本、快捷方式脚本、使用说明
3. 用 7za 压缩为 zip

**根本解决**：开启 Windows 开发者模式（设置 → 更新和安全 → 开发者选项），之后即可用 `npm run build` 生成 NSIS 安装包。
