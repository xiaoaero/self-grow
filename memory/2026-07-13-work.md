## 工作内容 3：维度经验计分规则重构（重大变更）

### 背景
将原来统一的 `exp_rate × floor(duration/15)` 公式拆分为 8 个维度各自独立的计分规则，并引入全局经验倍率概念。

### 核心变更
- **维度经验** × **全局倍率** = **全局经验**（global_rate: 0.5~1.0）
- 维度等级上限 120→140 级
- 8 维度各有独立计分规则：按时长/按次/按天/固定值

### 各维度规则

| 维度 | global_rate | 规则 |
|------|------------|------|
| 学习 | 1.0 | `floor(duration/20) × 10`，最小20分钟 |
| 健康-运动 | 1.0 | `floor(duration/15) × 3.75`，最小15分钟 |
| 健康-睡眠 | 1.0 | 基础20EXP，23:00后每4分钟扣1，6-9h有效 |
| 健康-作息规律 | 1.0 | 连续5天后第6天起每天+15，有保护机制 |
| 关系-线下 | 0.5 | +80/次 |
| 关系-线上 | 0.5 | `floor(duration/30) × 20`，最小30分钟 |
| 工作-日常 | 1.0 | +10/天，默认工作日 |
| 工作-加班 | 1.0 | 工作日+20，休息日+30 |
| 创作-产出 | 0.5 | 120/h |
| 创作-素材 | 0.5 | 40/h，最小30分钟 |
| 创作-发布 | 0.5 | +160/次 |
| 财务-学习 | 0.5 | 80/h |
| 财务-复盘 | 0.5 | +100/次，每月限1次 |
| 爱好 | 0.75 | 40/h |
| 魅力 | 0.5 | 50/h |

### 新增子类型系统
- 健康：运动/睡眠（睡眠需输入睡觉起床时间）
- 关系：线上/线下
- 工作：日常/工作日加班/休息日加班（按日期默认）
- 创作：产出/素材/发布
- 财务：学习梳理/月度复盘
- 学习/爱好/魅力：无子类型，直接计时

### 作息规律保护机制
- 连续10天规律获得一次保护机会（不可叠加）
- 消耗保护当天不加经验但连续天数不重置
- 消耗后重新计算10天才能再次获得保护

## 工作内容 6：AI 行动解析功能实现

### 功能概述
在"开始行动"页面的"描述记录"模式下，用户可以用自然语言描述行动，AI 通过多轮对话理解并计算经验值，最终由用户确认后批量提交。

### 核心设计
- **多轮对话**：AI 信息不足时反问用户，对话历史保留到提交
- **AI 精确计分**：AI 根据 `维度经验计分规则.md` 的公式计算 EXP，后端二次校验
- **多维度支持**：一段描述可拆成多条记录（如"学习2小时+跑步30分钟"→2条）
- **可编辑确认框**：用户可在预览中修改维度（下拉框）、时长、备注，再提交
- **模糊输入处理**：AI 调用 `send_message` 反问，直到收集足够信息

### 交互流程
```
用户输入 → [聊天界面，多轮对话] → AI 收集足够信息
  → AI 调用 submit_actions（含精确 EXP 计算）

  → POST /api/actions/ai-submit 批量创建记录
```
