## 0. 开工前：10 分钟环境准备

素材难看，90% 不是截图技术问题，而是**画面里没内容**。

| 步骤 | 操作 | 目的 |
|---|---|---|
| 1 | 用 `admin / admin123456` 登录 | 管理员才有技能树编辑器入口 |
| 2 | 浏览器开 `http://localhost:3001`，F12 → 设备工具栏 → 选 **1920×1080** | 统一尺寸，避免截图大小不一 |
| 3 | 把浏览器缩放到 **100%** | 避免 UI 被压缩变形 |
| 4 | 侧边栏走一遍，让热力图/雷达图/趋势图**都有真实数据** | 空图表是最掉分的画面 |
| 5 | 建 1 个目标（带 2 个里程碑）、3 个任务（todo/doing/done 各一）、1 个习惯并连打 3 天 | 让任务三栏和周视图有内容 |
| 6 | 在技能树编辑器里**造一棵 15~20 节点、3 层**的树（或让 AI 生成） | 空画布讲不出 AI 编辑能力 |
| 7 | 奖励商城上传 1~2 张图片 | 卡片不至于全灰 |
| 8 | 表达训练**答 1 道题**并拿到 AI 评分 | 历史页与评分区有内容 |

**统一前置状态**：所有截图都从"仪表盘"出发，保证侧边栏、等级徽章一致。

## 1. 工具选择（Windows）

| 用途 | 首选 | 备选 | 说明 |
|---|---|---|---|
| 静态截图 | **Snipaste**（F1 截图，带取色标注） | Win+Shift+S | 存 PNG，不要 JPG（文字会糊） |
| 屏幕录制 | **ScreenToGif**（录完直接编辑、删帧、加字幕、导出 GIF） | OBS + ffmpeg | ScreenToGif 一条龙，省事 |
| 格式压缩 | `gifski` / `gifsicle` | ScreenToGif 内置 | 控制单文件 < 3 MB |
| 图床 | 不需要——放 `docs/` 用相对路径 | — | GitHub 可直接渲染仓库内图片 |

**ffmpeg 备用命令**（若用 OBS 录 mp4 再转 GIF）：

```bash
# 1080p → 宽 900、15fps、高质量 GIF
ffmpeg -i input.mp4 -vf "fps=15,scale=900:-1:flags=lanczos,split[s0][s1];[s0]palettegen[p];[s1][p]paletteuse" -loop 0 output.gif
```

## 3. 动态 GIF：3 个杀手锏（各 12~18 秒）

**统一规范**

- 时长 **12~18 秒**，超过 20 秒没人看完
- 帧率 **12~15 fps**（够顺且体积小）
- 宽度 **900px**，单文件 **< 3 MB**
- **必须有字幕**：用 ScreenToGif 的「标题/文字」帧，3~4 句，每句 ≤ 12 字
- 鼠标要可见（开启指针高亮），动作之间**留 0.5 秒停顿**，别一闪而过

### 🎬 GIF-1：`demo/coordinator-agent.gif` — 统一协调 Agent

> 证明：多智能体编排 + 反问机制，这是全项目最值钱的一张

| 时间 | 画面动作 | 字幕 |
|---|---|---|
| 0-2s | 点击右下角悬浮球，对话框展开 | 「自然语言下达指令」 |
| 2-4s | 输入「帮我记录跑步 30 分钟」并发送 | —— |
| 4-7s | 出现**反问卡片**（缺时长/强度），停 1 秒 | 「信息不足 → 主动反问」 |
| 7-9s | 在卡片里补「30 分钟，中等强度」 | 「补充后继续执行」 |
| 9-13s | 显示工具调用结果 + 回复 | 「路由到 action 子 Agent」 |
| 13-16s | 切到「行动历史」，新记录已出现，EXP 数字跳动 | 「数据真实落库」 |

**关键**：结尾一定要有"数据变了"的镜头，否则看着像聊天机器人。

### 🎬 GIF-2：`demo/skilltree-ai.gif` — 技能树 AI（LangGraph）

> 证明：AI 真的在操作画布，不是生成一段文字

| 时间 | 画面动作 | 字幕 |
|---|---|---|
| 0-2s | 空画布（或只有 1 个根节点） | 「空画布」 |
| 2-4s | AI 面板输入「为『前端进阶』生成知识树」 | 「一句话描述需求」 |
| 4-6s | 出现**确认卡片**（将替换整棵树） | 「危险操作先确认」 |
| 6-8s | 点击「确认执行」 | —— |
| 8-14s | 节点**逐个出现在画布上**并自动连线 | 「批量生成 + 自动布局」 |
| 14-16s | `Ctrl+Z` 撤销，树回到之前状态 | 「AI 的改动可撤销」 |

**关键**：最后两秒的撤销是这个 GIF 的高光——它说明 AI 改动纳入了同一套状态管理。

### 🎬 GIF-3：`demo/expression-training.gif` — 表达训练

> 证明：实时性（语音 + 填充词）与 AI 评分闭环

| 时间 | 画面动作 | 字幕 |
|---|---|---|
| 0-3s | 点击「开始」，题目出现 | 「AI 出题（自动查重）」 |
| 3-8s | 开启语音输入，**边说边出字**（可打字模拟） | 「实时语音转写」 |
| 8-11s | 说/输入含「然后、就是、嗯」的段落 | 「实时填充词高亮」 |
| 11-14s | 点「完成」，AI 评分面板展开 | 「四维评分」 |
| 14-16s | 展开提示面板（方向 → 例子） | 「分层答题提示」 |

> 若无麦克风环境，用打字即可；字幕保留「实时语音转写」无妨，但**别在面试里声称自己测过语音**——诚实更稳。
